# bancodedadosrpg
Nesta atividade, você deverá implementar a estrutura de um banco de dados para um jogo de RPG online utilizando a linguagem SQL.
Para realizar a atividade, utilize o diagrama do banco de dados fornecido nesta atividade como referência. A partir dele, você deverá identificar as entidades, atributos, chaves primárias, chaves estrangeiras e relacionamentos definidos no modelo e implementar as respectivas tabelas no banco de dados.
